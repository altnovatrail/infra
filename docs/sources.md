# infra — источники

> Внешние факты, на которые опираются документы `docs/`: условия поставщика, цена, закон, стандарт, документация программы. Здесь — их записи: адрес, версия или дата страницы, дата прочтения и цитата на языке источника, — а [architecture.md](architecture.md) держит утверждение и ссылку на запись по её номеру, как на раздел: `sources 1.1` (RULES.md, The bar; R143 spec; R26).
>
> Запись — подраздел «N.M» темы: один источник или одно чтение нескольких источников для одного решения. Номер записи не меняется: новая встаёт в конец своей темы, новая тема — в конец файла. Источник, прочитанный заново, — пункт со своей датой в той же записи, а прежний текст не правится. Образец — sources spec. Итогов замеров здесь нет: их место — `docs/measurements.md`, который заводит первый замер. Цитаты, которые запись журнала решений даёт сама, остаются в записи: журнал не переписывается.
>
> До T52 записи стояли разделом 4 [architecture.md](architecture.md), по пункту на источник. T52 перенесла их дословно, по теме на часть устройства, а ссылку на раздел в начале пункта — `(раздел 2.1)` — записала как `(architecture 2.1)`: голое «раздел» здесь означало бы раздел этого файла. Заголовок записи — прежнее имя пункта, так что пункт, который называют журнал и архивы `docs/plan/`, находится по нему. Файл на русском, пока T53 не переведёт `docs/` (R26).

(architecture 2.1–2.4, 3.2) — [mathtrail/canvas-api](https://github.com/mathtrail/canvas-api/tree/0901af0), коммит 0901af0, прочитано 2026-10-19, а цитаты R45 и R58 canvas-api, его environments, `service_api.tf` и `justfile` — 2026-11-08:
- `docs/decisions.md`: R54 canvas-api — весь контур в `us-east4`, потому что в бете только семьи из США; R55 canvas-api — API по адресу `*.run.app`, приложение по адресу Firebase Hosting `web.app`, своего домена нет: «свой домен не нужен закрытой бете по приглашениям, а domain mapping Cloud Run в Preview»; R57 canvas-api — журналы в бакете `default-us-east4` на 30 дней, `_Required` остаётся в `global`, место трасс задано до первой трассы; R45 canvas-api и R58 canvas-api — выкладка после релиза, из его тега: «выкладка идёт, только если `main` всё ещё стоит на этом коммите. Иначе перезапуск CI старого коммита откатил бы prod», «Выкатываются подписанные файлы релиза, а не сборка из тега», после отката — `update-traffic --to-latest`; у environment `prod` и `prod-hosting` только правило ветки `main`, без reviewers (API GitHub, прочитано 2026-11-08); `justfile`, комментарий к `ci-hosting-check`: «a browser that kept it would ask for the files of a release that the next one removed»; в `infra/terraform/service_api.tf` образ — в `ignore_changes`, и выкладка ставит его по digest из push, мимо Terraform;
- `infra/terraform/logging.tf` — бакет журналов в регионе проекта и sink `_Default`, перенаправленный в него с прежним фильтром; фильтра исключения журналов запросов в нём нет;
- `docs/privacy.md`, таблица открытых вопросов: «Журналы запросов Cloud Run с IP-адресами» — варианты «оставить 30 дней; исключить часть журналов; сократить срок», рекомендация — «сократить срок хранения журналов запросов до минимума, нужного для безопасности».
